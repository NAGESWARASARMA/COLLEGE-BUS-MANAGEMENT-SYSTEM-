🚌 College Bus Management System

A Python-based application to manage college bus details and track bus arrivals and departures using QR code scanning.

✨ Features

- 🚌 Register and manage bus details
- 👨‍✈️ Store driver information
- 🛣️ Manage routes, stops, and schedules
- 📷 Scan bus QR codes using a webcam
- 🕒 Record arrival and departure scan events with timestamps
- 📋 View registered buses and scan history
- 🗄️ Store records in an SQLite database
- ⚙️ Configure automatic startup on Windows

🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML and CSS
- OpenCV
- QR Code Scanning

⚙️ How It Works

1. Register a bus in the application.
2. Create a QR code containing its registered bus ID.
3. Start the camera scanner.
4. Scan the QR code.
5. View the recorded scan and timestamp.

🎯 Project Objective

To simplify college bus record management and reduce repetitive manual data entry.
